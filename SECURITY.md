# Reporting a security problem

Easy MVT is used by people who may be targeted by spyware, so security problems matter a lot.

**Please don't open a public issue for security problems.** Instead, report them privately via
GitHub: open the repository's **Security** tab → **Report a vulnerability**.

Please include what you found, how to reproduce it, and which version and operating system
you used. You'll get an answer as soon as possible.

Problems in MVT itself (the forensic engine) should go to the
[MVT project](https://github.com/mvt-project/mvt/security).
